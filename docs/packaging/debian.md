# ForgeKit Debian Packaging Documentation

This document describes the Debian packaging for ForgeKit, including build process, testing, and submission guidelines.

## Package Information

- **Package name**: `forgekit`
- **Binary name**: `forgekit` (with `forge` symlink for backward compatibility)
- **Version**: 0.3.4+
- **Section**: devel
- **Priority**: optional
- **License**: MIT
- **Architecture**: amd64, arm64
- **Maintainer**: ForgeKit Maintainers <forgekit@demetrius-ch.github.io>
- **Homepage**: https://github.com/Demetrius-ch/forgekit
- **VCS**: https://github.com/Demetrius-ch/forgekit.git

## Architecture

```
forgekit (package)
    │
    ├── /usr/bin/forgekit          # Main binary (statically linked Go binary)
    ├── /usr/bin/forge             # Symlink → forgekit (backward compatibility)
    ├── /usr/share/icons/hicolor/scalable/apps/forgekit.svg
    ├── /usr/share/metainfo/com.forgekit.ForgeKit.metainfo.xml
    ├── /usr/share/doc/forgekit/
    │   ├── changelog.Debian.gz
    │   └── copyright
```

## Build Process

### Using GoReleaser (Recommended)

The Debian package is built automatically via GoReleaser using nfpm:

```bash
# Build snapshot
goreleaser release --snapshot --clean

# Build release (requires git tag)
git tag v0.3.1
goreleaser release --clean
```

### Configuration

Key configuration files:
- `.goreleaser.yaml` - GoReleaser configuration with nfpm settings
- `debian/changelog` - Debian changelog
- `debian/copyright` - Copyright information
- `packaging/com.forgekit.ForgeKit.metainfo.xml` - AppStream metadata
- `packaging/icons/hicolor/scalable/apps/forgekit.svg` - Application icon

### Dependencies

- **Depends**: `libc6`, `ca-certificates`
- **Recommends**: `docker.io`, `docker-compose-v2`
- **Build-Depends**: `golang-go` (for building from source)

The binary is statically compiled with `CGO_ENABLED=0`, so it has minimal runtime dependencies.

## Testing

### Lintian Validation

```bash
# Install lintian
sudo apt update && sudo apt install lintian

# Validate package
lintian forgekit_*.deb
```

Expected results (as of v0.3.4):
- **Errors**: `statically-linked-binary` (expected for Go binaries)
- **Warnings**: `initial-upload-closes-no-bugs`, `no-manual-page [usr/bin/forge]`, `unknown-field Architecture-Variant`

All critical issues are resolved. The `statically-linked-binary` error is expected
for Go binaries compiled with `CGO_ENABLED=0`. The `no-manual-page` warning is
for the `forge` symlink (which points to `forgekit`).

### AppStream Validation

```bash
# Install appstreamcli
sudo apt update && sudo apt install appstream

# Validate metadata
appstreamcli validate packaging/com.forgekit.ForgeKit.metainfo.xml
```

Expected: Passes with info-level warnings only.

### Functional Testing

```bash
# Install package
sudo dpkg -i forgekit_*.deb

# Test commands
forgekit version
forge version          # backward compatibility
forgekit --help
forgekit init test-project
forgekit doctor
forgekit analyze
```

## Installation

### From APT Repository (Recommended)

```bash
# Add GPG key (Deb822 format)
curl -fsSL https://demetrius-ch.github.io/forgekit/forgekit-archive-keyring.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/forgekit-archive-keyring.gpg

# Add repository
echo "deb [signed-by=/usr/share/keyrings/forgekit-archive-keyring.gpg] https://demetrius-ch.github.io/forgekit stable main" \
  | sudo tee /etc/apt/sources.list.d/forgekit.sources

# Install
sudo apt update && sudo apt install forgekit
```

### From .deb File

```bash
VERSION=0.3.1
wget https://github.com/Demetrius-ch/forgekit/releases/download/v${VERSION}/forgekit_${VERSION}_linux_amd64.deb
sudo dpkg -i forgekit_${VERSION}_linux_amd64.deb
```

### Uninstall

```bash
sudo apt remove forgekit
```

## Migration from `forge` package

The package provides migration support from the old `forge` package:

- `Replaces: forge` - Replaces the old package
- `Provides: forge` - Provides virtual package `forge`
- `/usr/bin/forge` symlink maintained for backward compatibility

Migration test:
```bash
# Install old package (if available)
sudo apt install forge

# Install new package
sudo apt install forgekit

# Both commands work
forge version
forgekit version
```

## Debian Submission Checklist

For official Debian submission:

- [ ] Package builds reproducibly
- [ ] Lintian passes (errors resolved)
- [ ] AppStream metadata valid
- [ ] Copyright file complete (MIT + CC0-1.0 for AppStream)
- [ ] Changelog follows Debian format
- [ ] Source package available (`dpkg-source -b`)
- [ ] Build logs clean
- [ ] Test suite passes (`go test ./...`)
- [ ] No embedded libraries (statically linked Go binary is acceptable)
- [ ] Man pages (optional but recommended)
- [ ] Debconf templates if needed (not needed for ForgeKit)

## Maintenance

### Updating Version

1. Update version in git tag: `git tag v0.3.2`
2. GoReleaser automatically extracts version from tag
3. Debian changelog should be updated manually or via automation

### Security Updates

For security updates, follow Debian security team process:
1. Prepare fixed version
2. Build with security-only changes
3. Upload to security archive

## CI/CD Integration

The packaging is integrated with GitHub Actions:

- `.github/workflows/release.yml` - Builds and publishes release artifacts
- `.github/workflows/apt.yml` - Builds and publishes APT repository
- `.github/workflows/snap.yml` - Builds and publishes Snap

All workflows triggered on git tag push (v*).

### ITP Submission Steps

1. Verify package doesn't exist in Debian:
   ```bash
   apt-cache search forgekit
   # Check https://packages.debian.org/search?keywords=forgekit
   ```

2. Submit ITP bug report:
   ```bash
   # Use the template in docs/packaging/ITP.txt
   # Submit to: submit@bugs.debian.org
   ```

3. Prepare source package:
   ```bash
   # Build source package
   dpkg-buildpackage -S -sa
   
   # Or with debhelper
   debuild -S -sa
   ```

4. Find a sponsor via mentors.debian.net
