# ForgeKit v0.4.0 — Custom Project Generation

ForgeKit v0.4 introduces customizable project generation. Instead of imposing a single project layout, developers choose the architecture, database, and optional components that fit their needs.

## What's New

### Interactive Mode

```bash
forgekit init my-api
```

Presents a configuration menu:

```
Project configuration

Architecture
> Hexagonal
  Clean Architecture
  Layered

Database
> PostgreSQL
  MySQL
  SQLite
  None

Docker
> Yes
  No

Authentication
> None
  JWT

API documentation
> None
  Swagger

Tests
> Unit + Integration
  Unit only

CI/CD
> None
  GitHub Actions
```

After review, the project is generated with only the selected components.

### Non-Interactive Mode

```bash
forgekit init my-api \
  --non-interactive \
  --architecture hexagonal \
  --database postgres \
  --docker \
  --auth jwt \
  --docs swagger \
  --tests unit-integration \
  --ci github-actions
```

### Configuration via File

```bash
forgekit init my-api --config forge.yaml
```

```yaml
project:
  name: my-api
  language: go
  module: github.com/user/my-api
  database: postgres
  docker: true
  authentication: jwt
  documentation: swagger
  tests: unit-integration
  ci: github-actions
```

```bash
forgekit init my-api --dry-run
```

## Supported Architectures

### Hexagonal

```
cmd/server/main.go
internal/
  domain/
  application/
  transport/http/
  infrastructure/
migrations/
```

### Clean Architecture

```
cmd/server/main.go
internal/
  entities/
  usecases/
  interfaces/http/
  infrastructure/
migrations/
```

### Layered

```
cmd/server/main.go
internal/
  models/
  services/
  handlers/
  infrastructure/
migrations/
```

## Supported Databases

| Database | Driver | Migrations | Docker Service |
|----------|--------|------------|----------------|
| PostgreSQL | pgx/v5 | Yes | postgres |
| MySQL | go-sql-driver | Yes | mysql |
| SQLite | modernc.org/sqlite | Yes | None |
| None | None | None | None |

## Optional Components

| Component | Flag | Default |
|-----------|------|---------|
| Docker | `--docker` | true |
| Authentication | `--auth` | none |
| API Docs | `--docs` | none |
| Tests | `--tests` | unit |
| CI/CD | `--ci` | none |

## Validation

ForgeKit validates the configuration before generation:

- Rejects invalid values (e.g., `--database mongo`)
- Detects inconsistent combinations
- Produces clear error messages

## Compatibility

- All v0.3 commands (`add`, `remove`, `doctor`, `check`, `analyze`, `inspect`) continue to work
- The `--non-interactive` flag works for all v0.4 options
- Default behavior (`forgekit init my-api`) is close to v0.3 output
